# UNSPSC dataset facts (verified)

Checked on 2026-10-16 against `CIIS-ZCMC/zcmc-product-catalogue-server` (default branch). Facts change when
the server reseeds, so re-run the checks below before relying on a number.

## Source and version

- Seed file: `database/data/unspsc_categories.csv` (about 65 MB), loaded by `database/seeders/CategorySeeder.php`.
  If it is missing, the seeder falls back to the smaller `database/data/categories.csv`, so check which one a given server used.
- The CSV was generated by `database/data/generate_unspsc_csv.py` from a local `unspsc_english.xlsx` export.
- **No UNSPSC version or release date is recorded** in the CSV, the script, the database schema or the README.
  The version is **unknown**. Do not state one in UI, docs or PRs until the server team confirms it.

- Columns: `key, parent_key, code, title, level, path, definition`. `definition` is filled on 143,628 rows.
- There are **no keywords, synonyms or alternate titles** in the CSV or in the `categories` table
  (`key, parent_key, code, title, definition, level, path, timestamps`).
- `key` is the server's internal id (official rows use keys 100001–283976). `code` is the 8-digit UNSPSC code.
  They are different numbers. Never send one where the other is expected.

## Non-official rows

- `POST /categories` (the UNSPSC explorer's create form, `CategoryService::createCategory`) assigns
  `key >= 9000000`, and `StoreCategoryRequest` accepts any `code` (nullable, max 50) and `title`. Rows like these
  are **local additions, not UNSPSC**. Treat any key ≥ 9000000 as unverified unless proven otherwise.

## Search behavior

- `GET /categories/commodities?q=&limit=` → `CategoryService::searchCommodities`. It returns level 3 only, 40 by default.
  - Matching is `Category::scopeSearch`: `title LIKE %q% OR code LIKE %q% OR key LIKE %q%`. The whole query is
    **one exact substring**: no tokenizing, stemming, synonyms or ranking. For example, "ballpoint pens" does not match
    "Ball point pens" (44121704). A partial code such as "441217" matches by prefix or substring.
  - An empty `q` returns a fixed list of 15 curated hospital commodity codes. All 15 were checked and exist in the dataset.
  - Each result has `key, code, title, level, definition, full_path, relations{segment, family, class (+ _code), commodity, commodity_code}, hierarchy[]`.
- `GET /categories/search?q=&level=&limit=` → `CategoryService::search`. It searches any level, needs at least 2 characters, and returns 30 by default.
- `GET /categories/roots`, `/categories/{key}/children` and `/categories/{key}` support tree browsing.

## How product saves use it

- `StoreProductRequest` needs `category_key` (`exists:categories,key`). It does **not** require level 3.
  `unspsc_code` is free text there, but `ProductService` overwrites it with the category's `code` when the category has one.
- `erp_item_code` = `[category code]-[internal category code]-[2-digit seq]`, generated by the server
  (`GET /products/next-erp-code` gives a preview).
