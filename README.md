# ZCMC Product Catalogue — Frontend Web Application

> **Republic of the Philippines • Department of Health**  
> **Zamboanga City Medical Center (ZCMC) — Procurement Management Unit**  
> Single-Page Application for Standardized Item Classification & Procurement Catalogue Management

---

## Overview

The **ZCMC Product Catalogue Client** is a modern, high-performance web application built with **React 19**, **Vite**, and **Material UI**. Designed specifically for the ZCMC Procurement Management Unit, it streamlines product registration, ensures uniform item naming standards, visualizes complex 4-level UNSPSC category trees, and synchronizes institutional codes across hospital workstations.

---

## Key Features

- **Commodity-First Classification:** Direct search and selection of UNSPSC Commodities with automatic resolution of parent Segment, Family, and Class.
- **Institutional Internal Category Integration:** Dropdown/autocomplete for 32 ZCMC hospital internal categories (e.g. ME-SUP, OF-SUP, DR-MED).
- **Autogenerated ERP Item Code:** Real-time generation of locked codes adhering to [category_code]-[internal category code]-[seq starting at 01] (e.g., 44121704-OF-SUP-01).
- **Hospital Uniform Naming Assistant:** Live syntax analysis, uppercase formatting assistant, and duplicate detection alerting staff of similar existing items.
- **System Code Compliance:**
  - **BizBox Item Code:** Required hospital inventory code input.
  - **PhilGEPS Code:** Required portal code with integrated quick link leading directly to the official [PS-PhilGEPS Common-Use Items Directory](https://ps-philgeps.gov.ph/home/index.php/what-we-sell/common-use-items).
- **Technical Specifications Builder:** Interactive semicolon tag builder for clean, delimited technical specs.
- **Zero-Config LAN Connectivity:** Dynamically resolves API requests via window.location.hostname allowing any authorized laptop/PC on the hospital network to access the web portal.
- **Bulk CSV Data Operations:** Instant template exports and file uploads for bulk items.

---

## Tech Stack

- **Framework:** React 19 + Vite
- **UI Components:** shadcn/ui + Tailwind CSS v4 (products and app shell); Material UI + Emotion for screens not yet migrated (sign-in, dashboard, activity logs, CSV import)
- **Routing / forms:** React Router, React Hook Form + Zod
- **Icons:** Material Icons & Lucide React
- **Network / HTTP:** Fetch API with dynamic hostname resolution

## Installation & Setup

### Prerequisites
- Node.js >= 18.0.0
- npm >= 9.0.0
- Running instance of [ZCMC Product Catalogue Server](https://github.com/<your-organization>/zcmc_product_catalogue_server)

### Quick Start

1. **Clone the repository:**
   `ash
   git clone https://github.com/<your-organization>/zcmc_product_catalogue_client.git
   cd zcmc_product_catalogue_client
   `

2. **Install dependencies:**
   `ash
   npm install
   `

3. **Configure environment (Optional):**
   `ash
   cp .env.example .env
   `
   *Note: If VITE_API_BASE_URL is omitted, the app dynamically connects to http://<current-host-ip>:8000/api, ensuring LAN devices work automatically.*

4. **Start local development server:**
   `ash
   npm run dev
   `
   The application will be accessible at:
   - Local: http://localhost:5173/
   - Network: http://<your-lan-ip>:5173/

5. **Build for production:**
   `ash
   npm run build
   `
